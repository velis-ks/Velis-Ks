## Featured Projects

### Player Performance & Telemetry Dashboard
A robust, MVC-based web application designed to manage leagues, teams, and players while tracking their evolving performance metrics through automated data ingestion. Built with CodeIgniter 4, the platform processes weekly telemetry data via strict CSV uploads, applies custom mathematical weights to specific competences (IMA/IMH), and visualizes the evolution on interactive analytical dashboards.
**Key Features:** Automated CSV Ingestion • Mathematical Data Weighting • Interactive Dashboards • Gamified Roster Management

### Fence-Pro
A comprehensive web application designed for complete management of fencing federations and clubs. The platform enables coaches, sports managers, and administrators to optimize their operational processes by digitalizing tasks traditionally done manually or through scattered tools.
**Key Features:** Club Management • Athlete Tracking • Event Organization • Digital Workflows
